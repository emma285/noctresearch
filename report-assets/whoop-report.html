    실제 수면 시간 vs 필요 수면 시간 DATA BY WHOOP

    필요 수면 시간 = WHOOP이 매일 계산한, 그날 밤 필요한 잠의 양 (어떻게 정해졌는지는 바로 아래 섹션)
    부족 = 필요 수면 시간에서 실제 수면 시간을 뺀 시간

    지표:실제 수면 시간수면 부족량필요보다 더 잔 만큼

    필요 수면 시간은 어떻게 정해졌나 DATA BY WHOOP

    필요 수면 시간 = 기본 필요 수면 + 수면 부채 + 활동량 보정 − 낮잠 보정
    · 기본 필요 수면: 지금까지 기록으로 정한 평소 필요량
    · 수면 부채: 최근 덜 자서 밀린 잠
    · 활동량 보정: 낮 활동이 많았던 만큼 더 필요한 잠
    · 낮잠 보정: 낮잠으로 이미 채워서 빼는 잠

    지표:기본 필요 수면수면 부채활동량 보정낮잠 보정
